# Stellar Journey to Mastery — Levels 4–7 Requirements

> Markdown conversion of the program requirements supplied to this project.
> Original wording is preserved; formatting was normalized for repository readability.

## 🟢 Level 4 - Green Belt Submission

### Overview

Congratulations on getting your idea approved! Now it’s time to transform your concept into a real production-ready MVP with actual users.

In this level, you will focus on building a scalable and polished product on Stellar with proper architecture, user onboarding, performance optimization, and real-world usability.

This stage is designed to help builders move beyond prototypes and start thinking like startup founders and product engineers.

### Focus

Production-Ready MVP + Real Users + Product Validation

### Learning outcomes

- Building scalable production-ready dApps
- Advanced frontend and backend architecture
- Real-world user onboarding
- Product validation and feedback collection
- Performance optimization
- Error tracking and monitoring
- Smart contract optimization
- Analytics and usage tracking
- Product presentation and demo preparation

💰 At the end of the monthly review period, selected winners will receive a prize based on the quality of their submission, and each winner will receive $100.

### Requirements

Your project must include all items below to successfully complete Level 4.

#### Production MVP

- Build a fully functional production-ready MVP
- Stable frontend and smart contract architecture
- Mobile responsive UI
- Proper loading states and error handling

#### User Onboarding

- Minimum 10 real users onboarded
- Proof of wallet interactions required
- Basic user feedback collection mandatory

#### Product Quality

- Production deployment required
- Monitoring and analytics integration
- Optimized user experience
- Proper project structure and documentation

#### Technical Standards

- Smart contracts deployed on Stellar testnet
- Minimum 15+ meaningful commits
- Public GitHub repository required

#### Demo & Review

- Live demo video showcasing complete functionality
- Team review for:
  - Technical complexity
  - Product quality
  - Architecture quality
  - Real-world usefulness

### Submission checklist

Ensure your project meets all requirements before submitting.

- Public GitHub repository
- README with complete documentation
- Minimum 15+ meaningful commits
- Live demo link
- Contract deployment address
- Screenshots showing:
  - Product UI
  - Mobile responsive design
  - Analytics or monitoring setup
- Demo video link
- Proof of 10+ user wallet interactions
- Basic user feedback summary

## 🔵 Level 5 - Blue Belt Submission

### Overview

Your MVP is now live — it’s time to grow, improve, and validate your product with a larger audience.

In this level, your focus will shift from just building to scaling. You will improve your product based on real user feedback, onboard more users, and prepare your project for ecosystem exposure through presentations and demos.

This stage is designed to simulate early-stage startup growth and product iteration.

### Focus

User Growth + Product Iteration + Pitch & Demo

### Learning outcomes

- Scaling user onboarding
- Product iteration using feedback
- Growth and retention strategies
- Product positioning
- Pitch deck preparation
- Product storytelling and demos
- Ecosystem presentation skills

💰 At the end of the monthly review period, selected winners will receive a prize based on the quality of their submission and each winner will receive $150.

### Requirements

Your project must include all items below to complete Level 5 successfully.

#### User Growth

- Minimum 50 testnet users onboarded
- Real transaction activity required
- Active usage proof mandatory

#### Product Improvements

- Add new features based on user feedback
- Improve UX/UI and product stability
- Optimize onboarding experience

#### Product Presentation

- Create a professional pitch deck/PPT
- Explain:
  - Problem statement
  - Solution
  - Market opportunity
  - Architecture
  - Growth strategy
  - Future roadmap

#### Demo

- Record a full product walkthrough/demo
- Showcase user flow and real use cases

#### Technical Standards

- Minimum 20+ meaningful commits
- Updated documentation required

### User onboarding evidence

- Create a Google Form to collect user details, including wallet address, email, name, and product feedback(rate your product).
- Export all responses into an Excel sheet for analysis and record-keeping.
- Attach or link the exported Excel sheet in your project’s README file.
- Clearly outline in the README how you plan to improve and evolve your project in the next phase based on the collected user feedback (Make sure you add git commit link in the improvement section)

### Submission checklist

- Public GitHub repository
- Minimum 20+ meaningful commits
- Live deployed application
- PPT/Pitch deck link
- Demo video link
- Proof of 50+ users
- Screenshots of analytics or transaction activity
- Updated README and documentation
- User feedback iteration summary

Submit your GitHub repository link below before the monthly deadline.

## ⚫ Level 6 - Black Belt Submission

### Overview

This is the final stage of the Stellar Builder Challenge.

At this level, your project should evolve into a real ecosystem product ready for public usage and long-term growth.

You will launch your application on Stellar mainnet, onboard real users, complete security checks, and promote your product publicly within the ecosystem.

This level is focused on turning builders into founders and production-ready teams.

### Focus

Mainnet Launch + Security + Real Adoption

### Learning outcomes

- Mainnet deployment workflows
- Production-grade security practices
- Smart contract auditing process
- Real-world product scaling
- Ecosystem marketing and branding
- Community-led product growth
- Product launch execution

💰 At the end of the monthly review period, selected winners will receive a prize based on the quality of their submission and each winner will receive $200.

### Requirements

Your project must include all items below to successfully complete Level 6.

#### Mainnet Deployment

- Smart contracts deployed on Stellar mainnet
- Public production-ready application live

#### Real Adoption

- Minimum 20+ verified mainnet users
- Real on-chain transaction activity required

#### Security

- One of the following is mandatory:
  - Smart contract audit OR
  - Security review approved by mentors/team

#### Product Marketing

- Mandatory social media promotion required:
  - Product launch post/thread on Twitter/X
  - Demo or showcase content
  - Stellar ecosystem tagging encouraged

#### Ecosystem Contribution

- Complete at least one:
  - Technical blog
  - Workshop
  - Tutorial
  - Open-source contribution
  - Community session

#### Technical Standards

- Minimum 30+ meaningful commits
- Full documentation and production setup required

### User onboarding evidence

- Create a Google Form to collect user details, including wallet address, email, name, and product feedback(rate your product).
- Export all responses into an Excel sheet for analysis and record-keeping.
- Attach or link the exported Excel sheet in your project’s README file.
- Clearly outline in the README how you plan to improve and evolve your project in the next phase based on the collected user feedback (Make sure you add git commit link in the improvement section)

### Advanced features

Implement at least one of these advanced features to complete your Black Belt requirements.

- Fee Sponsorship - Gasless transactions using fee bump
- Cross-border Flows - SEP-24/SEP-31 anchor integration
- Multi-signature Logic - Multi-party approval for transactions
- Account Abstraction - Smart wallet with custom auth

### Submission checklist

- Public GitHub repository
- Minimum 30+ meaningful commits
- Live mainnet application
- Mainnet contract addresses
- Proof of 20+ mainnet users
- Transaction activity proof
- Audit/security review proof
- Twitter/X launch post link
- Demo video link
- Technical documentation
- User guide/documentation
- Community contribution link

Submit your GitHub repository link below before the monthly deadline.

> **Note:** Level 6 is all about leveling up. This phase is designed to be a continuous cycle. If you complete the Level 6 requirements early, do not wait—move immediately to the next month's goals. Onboard another 100 users (Mainnet) make core contributions to your smart contracts, and start fighting for the rewards. Level 6 never ends; keep onboarding users and improving your code!

## 🧡 Level 7 - Master Track Submission

### Overview

Welcome to Level 7 — the Founder Belt.

At this stage, your project is no longer just a launched application. The focus now shifts to sustainable growth, user retention, product-market fit, and building a real business on Stellar.

You are expected to continuously improve your product based on real user feedback, onboard new users, grow your brand, and demonstrate that people actively use and value what you have built.

This level is designed to help builders transition from shipping products to building startups.

### Learning outcomes

- Product iteration using user feedback
- User acquisition strategies
- Community building and growth
- Product analytics and user retention
- Startup growth fundamentals
- Ecosystem partnerships
- Brand building and marketing execution
- Founder mindset and long-term product development

At the end of the monthly review period, selected winners will receive a prize based on the quality of their submission and growth achieved during the month.

Each selected winner will receive $250 USD.

### Submission checklist

- Public GitHub repository
- Minimum 30+ meaningful commits
- Live production application (Live on vercel or other platform)
- Proof of 50+ new mainnet users
- Mainnet transaction proof
- User feedback sheet
- Product improvement commit links
- Monthly growth report
- Social media growth proof (50+ followers)
- Product update posts
- Community contribution proof
- Updated documentation

Submit your GitHub repository and growth report before the monthly deadline.
